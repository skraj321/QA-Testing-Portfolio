# Jira Project Management

## Overview

This folder showcases my hands-on experience with **Jira Software**, one of the most widely used Agile project management tools. To gain practical knowledge, I created and managed my own Scrum project instead of only learning through tutorials. This helped me understand how development and QA teams collaborate throughout the Software Development Life Cycle (SDLC).

To make the learning practical, I developed a sample project named **SpiceSprint**, where I planned and managed software development activities using Agile and Scrum methodologies.

- Created Scrum Project
