## Folder Description

### Test Cases

This section contains manually designed test cases prepared for different web applications. Each test case includes:

- Test Case ID
- Test Scenario
- Preconditions
- Test Steps
- Expected Result
- Actual Result
- Test Status

Examples:

- Facebook Sign Up Test Cases
- SpiceSprint Sign Up Test Cases

---

### Acceptance Testing (AT)

This folder contains Acceptance Testing documents used to validate application functionality against business requirements.

Acceptance testing includes:

- Feature Validation
- Requirement Verification
- Test Result Recording
- Final Acceptance Status

---

### Bug Reports

This section contains defects identified during application testing.

Each bug report includes:

- Bug ID
- Bug Summary
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status

Current assignments include bug reporting for real QA training projects.
