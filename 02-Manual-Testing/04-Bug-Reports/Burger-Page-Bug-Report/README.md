# 🍔 Burger Shop - Manual Bug Report

## 📌 Project Overview

This repository contains a comprehensive **Manual Testing Bug Report** for the **Burger Shop** web application as part of my QA Testing portfolio.

The objective of this project was to perform exploratory manual testing, identify functional defects, validate application behavior, and document reproducible bugs following industry-standard bug reporting practices.

---

# 🔥 High Impact Bugs

Some of the major issues discovered include:

- Duplicate user registration using the same email with different letter casing.
- Shopping cart quantity increases by **2** instead of **1**.
- Products are automatically removed while updating quantity.
- Shopping cart data is shared across different user accounts.
- Checkout form accepts invalid input without validation.
- Weight Loss Calculator accepts invalid negative values.
- Weight Loss Calculator produces negative completion time.
- Meal Planner data is shared across different user accounts.
