# Forkify Bug Reporting Assignment

## Overview

This folder contains a bug reporting assignment completed during my **A1QA QA Academy** training. The objective was to perform functional and GUI testing on the **Forkify** web application, identify software defects, report them in **Linear**, and export the reported issues as a **CSV** file.

This assignment helped me understand the complete defect reporting workflow used by QA engineers in Agile teams.

---

## Project Details

- **Application:** Forkify
- **Testing Type:** Functional Testing & GUI Testing
- **Bug Tracking Tool:** Linear
- **Deliverable:** Exported Bug Report (CSV)

---

## Activities Performed

- Analyzed application requirements
- Explored different application modules
- Performed Functional Testing
- Performed GUI Testing
- Identified software defects
- Created bug reports in Linear
- Assigned severity and priority
- Documented steps to reproduce
- Verified expected and actual results
- Exported bug reports to CSV format

---

## Bug Report Includes

Each reported issue contains:

- Bug ID
- Bug Title
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
- Project Information
