# Automation Testing

## Overview

This folder contains Selenium automation frameworks developed to automate real-world web application workflows using industry-standard testing practices. The projects are built with **Java, Selenium WebDriver, TestNG, Maven, and the Page Object Model (POM)**, focusing on reusable, maintainable, and scalable test automation.

The frameworks include reusable components such as Base Class, Page Objects, Explicit Wait utilities, TestNG Listeners, Assertions, and Screenshot Capture on Test Failure. These features help improve code organization, test reliability, and maintainability.

## Projects

### SpiceSprint Selenium Automation
An end-to-end automation framework for a MERN-based online food ordering application. Automated scenarios include Login, Forgot Password, Search Food, Add to Cart, Checkout, Place Order, My Orders, and Logout.

### MakeMyTrip Flight Search Automation
A Selenium framework developed to automate the flight search workflow on the MakeMyTrip website, including source and destination selection, travel date selection, flight search, and result verification.
